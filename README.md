## 1. Introduction

This repository contains my solutions for the HackerRank Algorithms and GitHub Coding Portfolio activity completed as part of the 3rd Semester Computer Science and Engineering curriculum.

The main objective of this activity is to develop algorithmic problem-solving skills, implement efficient solutions using C++, analyze time and auxiliary space complexity, and maintain a well-organized GitHub coding portfolio.

The portfolio contains five algorithmic problems covering array processing, counting, insertion sorting, binary searching, sorting, and greedy techniques. Each solution is organized in a separate folder with a descriptive filename.

All applicable solutions were tested and submitted on HackerRank using C++20.
